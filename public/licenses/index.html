Native platform components

Lemera Android/iOS builds also bundle native libraries through Gradle and CocoaPods (for example CameraX via camera, scanner native code via mobile_scanner, and AndroidX). Those components are not enumerated in pubspec.lock.

Needs verification: a complete native third-party license list should be generated from a release build artifact (for example Android merged NOTICES) before final store submission.

Needs verification

  • Native Android/iOS SDK inventory and license texts for the exact Lemera release APK/IPA.
  • Any license type above if an upstream package changes its LICENSE file in a future lockfile revision.

네이티브 플랫폼 구성요소

Lemera Android/iOS 빌드에는 Gradle/CocoaPods를 통한 네이티브 라이브러리(예: camera의 CameraX, mobile_scanner 네이티브 코드, AndroidX)도 포함됩니다. 이들은 pubspec.lock에 나열되지 않습니다.

Needs verification: 최종 스토어 제출 전 릴리스 산출물(예: Android 병합 NOTICES)에서 네이티브 제3자 라이선스 전체 목록을 생성·검증해야 합니다.

Needs verification

  • Lemera 릴리스 APK/IPA의 네이티브 Android/iOS SDK 목록 및 라이선스 전문.
  • 향후 lockfile 변경으로 upstream LICENSE가 바뀌는 경우 해당 패키지 유형.
