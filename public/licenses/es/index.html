Lemera utiliza software de código abierto y componentes de terceros. Esta página publica la información sobre licencias de los paquetes Dart y Flutter incluidos en el archivo de dependencias resueltas de Lemera (apps/lemera/pubspec.lock). Se omiten los paquetes usados solo durante el desarrollo (flutter_lints, lints).

Acceso desde la aplicación

La aplicación Lemera abre esta página pública desde Gestión del grupo → Información → Licencias. Actualmente, Lemera ofrece los avisos de licencias mediante esta página web pública.

Componentes nativos de las plataformas

Las versiones Android e iOS de Lemera también incluyen bibliotecas nativas mediante Gradle y CocoaPods (por ejemplo, CameraX a través de camera, código nativo del escáner mediante mobile_scanner y AndroidX). Estos componentes no figuran en pubspec.lock.

Pendiente de verificación: antes del envío definitivo a las tiendas debe generarse una lista completa de licencias de terceros nativos a partir de un artefacto de lanzamiento (por ejemplo, el archivo NOTICES combinado de Android).

Pendiente de verificación

  • Inventario de SDK nativos de Android/iOS y textos de las licencias correspondientes al APK/IPA exacto de lanzamiento de Lemera.
  • Los tipos de licencia anteriores, si algún paquete cambia su archivo LICENSE en una futura revisión del archivo de dependencias.
